# Gemmini RTL frontend

This directory contains the minimal synthesizable RTL closure of the `Gemmini`
accelerator generated by Chipyard 1.14.0 `GemminiRocketConfig`.  The benchmark
top is the accelerator module itself, not the surrounding Rocket/TestHarness.

- Chipyard tag/commit: `1.14.0` / `0acc1e1de2d3284bcd4d876956932a013ffe1949`
- Gemmini submodule commit: `8c3f9923a44a2fe2c7930587be297d6d4f8c09ca`
- Imported generated RTL: 134 reachable modules plus two explicit SRAM
  blackboxes
- Clock/reset: `clock` / active-high `reset`
- SRAMs: four `mem_ext` (4096 x 128, 1RW) and two `mem_0_ext`
  (512 x 512, 1R1W)

The full Chipyard build tree is deliberately not vendored.  `rtl/` is the
audited reachable closure used by synthesis, and the retained BSD-3-Clause
`LICENSE` covers its redistribution.  PDK-specific LEF/Liberty views live with
the ng45 and ASAP7 platform collateral; they are physical-flow models, not
signoff SRAM characterizations.
